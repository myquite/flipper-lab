Every button runs a normal Flipper CLI command. Open the Console tab to see each command and the Flipper's reply.

Screen & remote

Mirroring switches the USB link into the Flipper's RPC mode (the same protocol qFlipper uses), so other tabs' commands wait until you stop it. Without mirroring, the buttons use input send <key> short. Keyboard: arrow keys, Enter = OK, Backspace = Back. Hold Shift for a long press.

Follow along on the live screen. With the mirror on, arrow keys, Enter and Backspace control the Flipper.
